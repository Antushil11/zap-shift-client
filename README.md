## ✨ Features

### 🔐 Authentication

* Firebase Auth
* Email/Password login
* Protected routes
* Role-based: **Admin vs User**

### 💳 Payment System

* Fully functional **Stripe checkout**
* Payment status tracker

### 📊 Admin Dashboard

* Manage users
* Manage bookings
* View transactions
* Analytics with **Recharts**

### 👤 User Dashboard

* Book services
* View booking history
* Make payments
* Interactive Map using **React-Leaflet**

### 🎨 Modern UI

* Tailwind CSS v4
* DaisyUI
* Lucide Icons
* Swiper Slider
* Lottie Animations

## ⚙️ Installation & Setup

### 1️⃣ Clone the repo

```bash
git clone https://github.com/<your-username>/zap-shift-client.git
cd zap-shift-client
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Create a `.env` file

```
VITE_apiKey=
VITE_authDomain=
VITE_projectId=
VITE_storageBucket=
VITE_messagingSenderId=
VITE_appId=
VITE_STRIPE_PK=
```

### 4️⃣ Start development

```bash
npm run dev
```

### 5️⃣ Build for production

```bash
npm run build
```

### 6️⃣ Preview production

```bash
npm run preview
```
